Ayaka 协作轻量端 使用说明
============================

【这是什么】
让没有安装 AyakaLauncher 的队友以最小的下载量加入房主的 Overleaf 协作网络。
只需房主的邀请码，即可在浏览器中协同编辑 LaTeX 文档。
加入时会自动为你创建一个协作账号（免注册），并把账号密码显示在窗口中，
粘贴到浏览器登录页一次即可，此后浏览器会保持登录。

【使用步骤】
1. 解压本文件夹到任意位置（保持目录结构完整，easytier 子文件夹必须与
   CollabLite.bat 在同一目录）。
2. 双击 CollabLite.bat 启动。
3. 向房主索取邀请码（形如 A/XXXX-XXXX-XXXX-XXXX），粘贴到「邀请码」输入框；
   可选在「显示名」输入框填写你的名字（留空默认 guest）。
4. 点击「加入协作」。程序会自动加入虚拟网络、寻找房主、建立转发，
   并自动创建协作账号（显示「协作账号已就绪」）。
5. 点击「打开协作页面」在浏览器中打开房主服务。
6. 首次打开时请在登录页分别粘贴窗口中展示的「邮箱」与「密码」
   （各有「复制」按钮，各粘贴一次）。登录一次后浏览器会保持登录，
   下次无需再粘贴。

【关于协作账号】
- 账号邮箱形如「显示名.abcd@collab.ayaka.local」，由你的显示名与本机标识
  自动生成；同一台机器重复加入同一邀请码会复用同一账号，不会重复开户。
- 账号密码由程序随机生成，经 Windows 加密后保存在本目录 collab-accounts
  文件夹中，仅本机当前用户可解密。
- 该账号由房主统一管理（停用、重置密码等）；如需修改，请联系房主在
  启动器「账号中心」操作。

【常见问题】
- 一直停留在「正在寻找房主…」：确认房主已在启动器「远程协作」页开启协作，
  且邀请码输入正确；超过 30 秒会自动提示失败。
- 提示「协作账号自动配对失败」：转发不受影响，可点击「重试配对」再试；
  若失败原因提示账号已存在，可修改「显示名」后重试（即换一个新账号），
  或联系房主重置密码。
- 提示账号已被停用 / 密码不一致：请联系房主在「账号中心」启用账号或
  重置密码后再「重试配对」。
- 防火墙提示：选择「允许访问」，否则无法与公共节点通信。
- 退出时请点击「断开」或直接关闭窗口，网络组件会一并停止。
- 邀请码等同密钥，请勿公开分享。

【系统要求】
- Windows 10 1607+ / Windows 11，64 位（x64 或 ARM64）
- 无需安装任何运行时（使用系统自带 PowerShell 与内置的 EasyTier 组件）

【组件说明】
内置 EasyTier v2.6.4（Apache-2.0 开源组网工具，
https://github.com/EasyTier/EasyTier），与主程序使用相同版本，
保证组网协议兼容。
